cow-rs · wasm end-to-end harness

Loads crates/cow-sdk-wasm/pkg/cow_sdk_wasm.js and exercises the Rust SDK from the browser. Built with --features in_shim_signing so the ECDSA panels work. Start with just wasm-harness then open http://localhost:8765/test-harness/.

Pure compute (no network)

1. compute_order_uid — UID parity

Derives the 56-byte order UID for a fixed sell-only order against the mainnet GPv2Settlement domain. Sanity-checks the byte length so regressions in OrderData::uid surface immediately.
