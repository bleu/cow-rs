cow-rs · wasm end-to-end harness

Loads crates/cow-sdk-wasm/pkg/cow_sdk_wasm.js and exercises the Rust SDK from the browser. Run with any static server in this repo's root, e.g. python3 -m http.server 8000, then open http://localhost:8000/test-harness/.
